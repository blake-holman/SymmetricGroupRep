# SymmetricGroupRep

Lean foundations for the representation theory of finite symmetric groups, built on mathlib.

The package covers Specht classification, Young subgroups, outer tensor
products, restriction and induction, branching, Pieri and
Littlewood--Richardson rules, regular and biregular decompositions, tableau and
hook-length dimensions, Young permutation modules, character projectors, and
explicit branching operators over `ℂ`.

Established representation-theoretic results are exposed through narrow,
sourced interfaces. Concrete permutation actions, finite-dimensional wrappers,
combinatorics, categorical reindexings, dimension consequences, projectors,
and matrix-unit laws are proved locally from mathlib and those interfaces.

See [ROADMAP.md](ROADMAP.md) for the completed capability map and source
pointers.
